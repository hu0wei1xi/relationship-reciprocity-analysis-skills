# Relationship Reciprocity Analysis Skills

本仓库包含两个用于关系互惠分析的 Codex Skills：

- 完整版：适合需要更完整分析框架的场景。
- 轻量版：适合快速、低开销的关系互惠分析。

## 目录结构

```text
relationship-reciprocity-analysis-skills/
├── relationship-reciprocity-analysis/
│   └── SKILL.md
├── relationship-reciprocity-analysis-lite/
│   ├── SKILL.md
│   └── README.md
└── README.md
```

## 安装方式

将所需的 skill 目录复制到 Codex skills 目录即可：

- 复制 `relationship-reciprocity-analysis` 使用完整版。
- 复制 `relationship-reciprocity-analysis-lite` 使用轻量版。
